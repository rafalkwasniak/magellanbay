## Technika warta zapamiętania

**Dokumentacja InPostu na Confluence obcina się przy zwykłym pobraniu strony.** Pełną treść, razem z blokami JSON, daje REST API bez logowania:

```
curl "https://dokumentacja-inpost.atlassian.net/wiki/rest/api/content/{ID}?expand=body.storage"
curl -G "https://.../wiki/rest/api/content/search" --data-urlencode 'cql=space=PL and text ~ "Raport COD"'
```

Bloki kodu siedzą w `<ac:plain-text-body><![CDATA[…]]>`. Bez tego dwa podejścia do dokumentacji wróciły z niczym.
