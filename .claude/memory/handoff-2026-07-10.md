Sort: Domyślnie / Kwota (rosnąco — jak Cena). Box **„Twoja sprzedaż"** pod filtrami: liczba zamówień, suma ilości produktów, przychód — liczone z CAŁEGO przefiltrowanego zbioru (nie tylko bieżącej strony). Usunięto zbędny licznik z nagłówka. Powrót ze szczegółu z kontekstem (`listQuery`), link „← Wróć do listy" pod lewą kolumną. Paginacja **10**.

**Nauczki/konwencje utrwalone tej sesji:**
- **Tailwind na produkcji:** dodanie NOWEJ klasy (np. `sm:grid-cols-3`) wymaga przebudowy CSS — a `npm run build` jest ryzykowny (patrz [[vite-build-rayon-threads]], [[orphaned-build-processes-incident]]). Dlatego trzymamy się klas JUŻ obecnych w `public/build/assets/app-*.css` (sprawdzać grepem). `lg:grid-cols-3` i `lg:grid-cols-4` są w buildzie; `sm:grid-cols-3` NIE.
- **Storefront `brand` = kolor podwójnego użytku:** tło przycisku (`.st-btn`) ORAZ tekst nagłówków/cen (`.st-brand`) na jasnym tle. Dlatego palety szablonów mają `brand` w mid-tonie (czytelny jako tekst), a nie jasny pastel. Stąd „Welurowa mgła" to przygaszone tony, nie pastele — świadomie. Pełne pastele wymagałyby zmiany, jak `.st-brand` liczy kolor tekstu (odłożone).
- `view:cache` po każdej zmianie Blade (produkcja cache'uje widoki). Config czytany na żywo (bez `config:cache`).
